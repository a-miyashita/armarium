# 03. UI

- Status: Draft
- Last updated: 2026-10-11

## 1. Screen layout

```
┌────────────────────────────────────────────────────────────────────────┐
│ Menu / toolbar  [+ Add] [Save] [Undo] [Redo] [SQL ▶]  Search…           │
├──────────────────┬─────────────────────────────────────────────────────┤
│ Source tree      │ Tabs: [sales.csv ●] [budget.xlsx / 2026] [Query 1]  │
│                  ├─────────────────────────────────────────────────────┤
│ ▼ CSV / TSV      │  #  │ id │ name   │ amount │ date       │            │
│   📄 sales.csv ● │  1  │ 1  │ Apple  │ 120    │ 2026-01-02 │            │
│   📄 users.tsv   │  2  │ 2  │ Banana │  80    │ 2026-01-03 │  Data grid │
│ ▼ Excel          │  …  │    │        │        │            │            │
│   ▼ 📗 budget.xlsx│                                                     │
│       ▦ 2025     ├──────────── (Split bar: can open and close) ─────────┤
│       ▦ 2026     │ SQL editor                                          │
│   ▶ 📗 plan.xlsx  │ SELECT name, SUM(amount) FROM sales GROUP BY name;  │
│                  ├─────────────────────────────────────────────────────┤
│                  │ Result grid / messages (for example, "3 rows updated")│
├──────────────────┴─────────────────────────────────────────────────────┤
│ Status bar: UTF-8 (BOM) │ Comma │ CRLF │ 12,345 rows × 8 columns │ Selected: 3 │
└────────────────────────────────────────────────────────────────────────┘
```

- The user can drag the border between the left pane and the right pane to change their widths. The user can collapse the left pane.
- The right pane has two parts: the data grid at the top, and the SQL editor and results at the bottom. The user can hide the bottom part.
- Armarium saves the pane widths, the split position, and the open tabs as the window state. Armarium restores them at the next start.

## 2. Left pane: source tree

### 2.1 Display

- Groups: "CSV / TSV" and "Excel". (Later, a setting can possibly select a flat list or a list by folder.)
- A CSV or TSV source is a leaf node. An Excel workbook is a node that has its sheets as child nodes.
- An Excel workbook with only one sheet also shows as a tree (for consistency).
- Status icons:
  - `●` The table has changes that are not saved.
  - `⚠` Armarium cannot find the file, or a read error occurred.
  - `↻` Another program changed the file (Armarium recommends a reload).
- The tooltip of a node shows the full path, the SQL name, the size, and the date of the last change.

### 2.2 Operations

| Operation | Result |
|---|---|
| Click, or Enter | Open the table. If the table is already open, make its tab active. |
| Drag and drop from Explorer | Register the file as a source. |
| "+ Add" on the toolbar, or Ctrl+O | Register files with a file dialog (the user can select more than one file). |
| Right-click → Unregister, or Delete | Remove the source from the workspace. Armarium does not delete the file. If there are changes that are not saved, Armarium asks the user to confirm. |
| Right-click → Rename SQL name | Change the SQL name. Armarium refuses a duplicate name. |
| Right-click → Show in Explorer | Show the file with `explorer /select,`. |
| Right-click → Reload | Read the file again. If there are changes that are not saved, Armarium asks the user to confirm. |
| Right-click → Read settings | Override the encoding, the delimiter, the header row, and other settings, and read the file again. |
| Right-click → Insert name into SQL | Insert the SQL name at the cursor position in the SQL editor. |

## 3. Right pane: tabs and data grid

### 3.1 Tabs

- There are two types of tabs: table tabs and query tabs.
- A tab shows the dirty mark (`●`).
- When the user closes a tab, Armarium keeps the working copy. The table stays dirty, and the tree shows `●`. To discard the changes, the user selects "Reload" or "Discard changes".

### 3.2 Data grid

- Virtual scrolling. The grid fetches only the visible rows ([ADR-0014](../adrs/0014-paged-grid-ipc.md)).
- Column header: the column name and a type icon. A right-click opens the column menu (sort, filter, change type, insert column, delete column, rename column).
- Row header: the row number (the order in the file). A right-click opens the row menu (insert above, insert below, delete).
- Sort and filter change only the display. They do not change the row order in the file. When Armarium saves the file, it writes the rows in the original order.
- The display can show NULL (empty cell) and an empty string differently. A setting controls this. For CSV, the default treats them as the same (see [06. Editing](06-editing.md)).
- Numbers align to the right. Other values align to the left.

### 3.3 Keyboard operations (main keys)

| Key | Action |
|---|---|
| Arrow keys, Tab, Enter | Move between cells |
| F2, or type a character | Start to edit |
| Esc | Cancel the edit |
| Ctrl+C, Ctrl+V | Copy, paste (TSV format, for use with Excel) |
| Ctrl+Z, Ctrl+Y | Undo, redo |
| Ctrl+S | Save |
| Ctrl+Shift+S | Save as, or export |
| Ctrl+F | Search in the table |
| Ctrl+Enter | Run SQL (in the SQL editor) |
| Delete | Clear the values of the selected cells |
| Ctrl+- , Ctrl++ | Delete rows, insert rows |

## 4. SQL editor and results

- CodeMirror 6 with SQL mode. The editor completes table names and column names (from the SQL names in the workspace and the schemas of the loaded tables).
- Range to run: the selected text if there is a selection. If not, all the text. Armarium runs more than one statement in sequence (separated by `;`).
- Results:
  - SELECT: a result grid (read-only), with "Export to CSV", "Export to Excel", and "Save as new source".
  - DML: a message with the number of rows that changed. The changed table becomes dirty, and the tabs and the tree show this.
  - Error: the error message. If possible, the editor also shows the position of the error.
- Armarium keeps a query history (the last 100 queries). The user can run a query from the history again.
- While a query runs, the UI shows a cancel button.

## 5. Dialogs

| Dialog | Purpose |
|---|---|
| Read settings | Encoding, delimiter, quote character, header row, number of rows to skip at the start, type inference on or off |
| External change warning (on save) | "Overwrite", "Reload (discard changes)", "Save as", "Cancel" |
| Unsaved changes (on exit) | A list of the tables that are not saved, with "Save all", "Do not save", "Cancel" |
| Export | Format (CSV, TSV, XLSX), encoding, line ending, BOM, header row |
| Settings | Language, theme (light, dark, system), cache size, NULL display |

## 6. Accessibility

- The user can do all operations with the keyboard.
- The colors are easy to identify in high contrast mode.
- The user can change the font size (Ctrl + mouse wheel).
